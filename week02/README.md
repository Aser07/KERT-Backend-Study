- init: `npm init -y`
- EJS, Express install: `npm install`
- start server: `node app.js`

## 구현한 라우트

* `GET /` : 첫 화면 (`/posts`로 전환)
* `GET /posts` : 글 목록 보여주기 (`?keyword=`로 특정 키워드의 글 검색 가능)
* `GET /posts/new` : 글쓰기 폼 조회
* `POST /posts` : 폼 데이터로 새 글 저장 후 상세 페이지로 전환
* `GET /posts/:id` : 글 상세 페이지 조회 (없는 글은 404 처리)
* `POST /posts/:id/delete` : 해당 글 삭제 후 다시 게시판으로 전환
